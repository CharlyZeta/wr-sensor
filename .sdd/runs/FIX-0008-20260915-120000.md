## Alcance de este fix (S1 + S2 + S3/A1/A6)
- **S1**: `docker-compose.yml` propaga `AUTH_JWT_SECRET` al gateway con el mismo default por entorno
  que el registry, y `GatewayConfig` valida el secreto contra los perfiles activos: **fail-fast** fuera
  de `dev`/`local`/`test`, WARN explícito dentro.
- **S3/A1**: `FiltroSeguridad` (HIGHEST_PRECEDENCE) aplica CSP, `nosniff`, `Referrer-Policy`,
  `X-Frame-Options`, `Permissions-Policy`, CORP y HSTS (sólo con `X-Forwarded-Proto: https`) a **toda**
  respuesta; `RespuestasGateway.propagable` descarta los headers de seguridad que venga del downstream
  para que el valor configurado sea el único (nunca duplicado ni pisado).
- **S2/A6**: `ServidorSpa` sirve `classpath:/static/` con resolución contenida y fallback explícito de
  rutas de cliente; prefijos reservados `/api/**` y `/ws/**`; caché `no-store`/inmutable.

## Fallos durante el Loop (3 iteraciones reales)
1. **YAML inválido en la CSP**: el valor se escribió entre comillas simples y contiene `'self'`, así
   que YAML cerraba el escalar antes de tiempo (`mapping values are not allowed here`) y el contexto
   de Spring no arrancaba (8 tests en error). Corregido usando comillas dobles; el test de docs
   verifica que `script-src` no tenga `unsafe-inline`/`unsafe-eval`.

   ajuste de la expectativa del test (sin ruta declarada corresponde `404 ROUTE_NOT_FOUND`; el `426`
   se verifica en `FEAT0008MainFlowIT`, que sí declara `/ws/**`).

## Justificación técnica de las decisiones no obvias
- **Headers en el gateway y no en cada servicio**: es el único punto de entrada publicado y el host
  del SPA; además `RespuestasGateway.propagable` garantiza un único valor por header, algo imposible
  si cada servicio los emitiera.
- **Fail-fast sólo fuera de desarrollo**: un gateway que acepta tokens forjables no debe arrancar por
  accidente en un entorno real, pero `docker compose up` en la máquina de desarrollo tiene que seguir
  funcionando sin configurar nada (con WARN explícito en el log).
- **`style-src 'unsafe-inline'` como única excepción**: Leaflet manipula atributos `style`; habilitar
  `script-src 'unsafe-inline'` anularía la protección justo en el vector que roba el token.
- **Lista explícita de rutas de cliente + prefijos reservados**: "todo lo que no matchea → índice"
  rompe el contrato de la API (`FEAT-0007` BR-008) y sirve HTML a un asset roto; la lista blanca es
  verificable y configurable.
- **`no-store` en el índice y caché inmutable por hash en los assets**: el índice referencia hashes
  nuevos en cada despliegue; cachearlo dejaría a los operadores con una versión vieja del panel.
