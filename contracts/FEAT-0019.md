## Intent

El repo ya aprueba el escaneo técnico (CI verde, licencia, suites trazables) pero pierde puntos en
tres señales de "cómo trabaja una persona detrás":

1. **Credenciales dev servidas en la configuración**: `Viewer123!` en `docker-compose.yml` y en los
   `application.yml` de `ingestion-service` y `query-api`. Un revisor lo lee como secreto filtrado.
2. **README solo en español**: el repositorio se presenta como portfolio internacional y el README
   es la primera impresión; sin versión en inglés pierde alcance.
3. **Falta la sección de decisiones y trade-offs**: un repo que solo muestra el resultado final
   (commit inicial de 15.525 líneas + scaffolding de agentes) lee como generado sin iteración. Una
   decisión **revertida** es la evidencia más difícil de falsear.

## Reglas del work item

- **BR-001:** Un único placeholder de credencial dev: `localdev`. No queda ningún `Admin123!` /
  `Viewer123!` en `docker-compose.yml` ni en `services/*/src/main/resources/*.yml`, y el stack dev
  sigue autenticando de punta a punta (seed, compose y defaults de los servicios alineados).
- **BR-002:** La documentación es bilingüe y **estructuralmente equivalente**: mismas secciones,
  mismas tablas, mismos números y los mismos bloques de diagrama (los diagramas **no** se traducen).
- **BR-003:** El español no se pierde: `README.es.md` conserva el contenido original y sigue siendo
  la referencia de los docs tests que verifican encabezados en español.
- **BR-004:** Traducción real, no automática: sin párrafos "gramaticales pero antinaturales" ni
  contenido perdido.
- **BR-005:** Cada decisión del registro declara su **costo**, no solo el beneficio, y al menos una
  es una decisión **revertida** con historia real de este repo (Primero hice / Se rompió por /
  Migramos a / Costo).
- **BR-006:** No se debilita ningún test de documentación para tapar un README roto: si un criterio
  cambia de idioma, el test se actualiza al invariante nuevo y deja nota de trazabilidad (patrón
  AF-03 de FEAT-0018).
